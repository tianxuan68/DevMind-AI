## 元数据模板

每份 Markdown 顶部必须包含：

```yaml
---
title: 文档标题
category: tech          # 意图类别
team: infra             # infra/backend/ops/hr
system: devmind_ai      # 所属系统
doc_type: wiki          # wiki/runbook/faq/report
version: 1.0
security_level: team    # public/team/confidential
last_updated: 2026-08-23
knowledge_base: 平台工程知识库
---
```

## 入库命令

```powershell
# 向量入库（Milvus）+ 同步 MySQL documents（知识库管理页展示）
uv run python -m internal_kb_qa.scripts.ingest_documents --recreate --dir internal_kb_qa/data/raw

# 仅写 Milvus、不同步 MySQL 时加 --no-sync-mysql
# ingest 默认会同步 MySQL；README.md 会自动跳过

# FAQ 入库（MySQL）
mysql -uroot -p internal_tech_kb < sql/seed_faq.sql
```

## 补充语料

通用意图语料仍位于 `internal_kb_qa/data/rag_seed/`，可与 raw 目录一并入库：

```powershell
uv run python -m internal_kb_qa.scripts.ingest_documents --recreate \
  --dir internal_kb_qa/data/raw \
  --dir internal_kb_qa/data/rag_seed \
  --file docs/Java开发手册(黄山版).pdf
```
