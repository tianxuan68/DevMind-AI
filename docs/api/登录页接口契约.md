# DevMind AI 登录页接口契约

服务入口：`http://localhost:8003/api/v1`。所有接口使用 HTTPS；浏览器采用 `HttpOnly`、`Secure`、`SameSite=Lax` 的刷新令牌 Cookie，前端仅在内存中保存短时 Access Token。

认证相关的数据表与安全约束见：[工作台数据库设计.md](../database/工作台数据库设计.md)。

## 统一响应

```json
{ "request_id": "req_xxx", "data": {}, "error": null }
```

失败时 `data` 为 `null`，`error` 例如 `{ "code": "INVALID_CREDENTIALS", "message": "账号或密码错误" }`。为避免账号枚举，登录、注册和验证码接口对不存在账号返回同一类通用提示。

## 账号密码登录

`POST /auth/password/login`

```json
{ "account": "zhang@example.com", "password": "<password>", "remember": true }
```

成功返回：

```json
{
  "request_id": "req_01",
  "data": {
    "access_token": "eyJ...",
    "token_type": "Bearer",
    "expires_in": 900,
    "user": { "id": "usr_01", "display_name": "张工程师", "department": "研发部" }
  },
  "error": null
}
```

`account` 可为企业邮箱、用户名或手机号。`remember=true` 时刷新令牌有效期可延长，但 Access Token 仍保持短时有效。

## 手机验证码

### 发送验证码

`POST /auth/phone/challenges`

```json
{ "phone": "+8613800138000", "purpose": "login" }
```

`purpose` 仅允许 `login`、`register`、`reset_password`。成功返回 `{ "challenge_id": "chl_01", "expires_in": 300, "retry_after": 60 }`。服务端必须按手机号、IP 和设备进行限流。

### 手机登录

`POST /auth/phone/login`

```json
{ "phone": "+8613800138000", "challenge_id": "chl_01", "code": "123456", "remember": false }
```

返回结构与账号密码登录相同。手机号未注册时返回 `PHONE_NOT_REGISTERED`，前端提示用户切换至注册。

## 注册账号

### 账号密码注册

`POST /auth/register/password`

```json
{
  "email": "zhang@example.com",
  "password": "<password>",
  "display_name": "张工程师",
  "organization_invite_code": "optional"
}
```

密码策略由服务端校验，建议至少 12 位并拒绝已泄露密码。成功后创建用户和本地身份，并返回登录令牌结构。

### 手机验证码注册

`POST /auth/register/phone`

```json
{
  "phone": "+8613800138000",
  "challenge_id": "chl_02",
  "code": "123456",
  "display_name": "张工程师",
  "organization_invite_code": "optional"
}
```

注册成功即标记 `phone_verified_at`，并返回登录令牌结构。手机号已绑定时返回 `PHONE_ALREADY_REGISTERED`。

## 会话与退出

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/refresh` | 使用刷新 Cookie 换取短时 Access Token |
| POST | `/auth/logout` | 撤销当前刷新令牌、清除 Cookie；前端跳转 `/` |
| GET | `/me` | 获取已登录用户的姓名、部门、头像与权限摘要 |

`POST /auth/logout` 无论会话是否已失效，都返回成功，确保客户端能安全地回到展示页。

## 前端状态映射

| 页面动作 | 调用接口 | 成功后的页面行为 |
| --- | --- | --- |
| 默认账号密码登录 | `/auth/password/login` | 保存短时令牌并跳转 `/workspace` |
| 点击“其他登录方式 → 手机验证码登录” | 无请求 | 切换为手机号表单 |
| 点击“获取验证码” | `/auth/phone/challenges` | 显示倒计时，禁止重复发送 |
| 手机验证码登录 | `/auth/phone/login` | 跳转 `/workspace` |
| 账号注册 | `/auth/register/password` | 自动登录并跳转 `/workspace` |
| 手机注册 | `/auth/register/phone` | 自动登录并跳转 `/workspace` |
| 工作台退出登录 | `/auth/logout` | 清除本地访问令牌并跳转 `/` |

当前前端仅实现表单和页面跳转 Mock；上述接口是后端接入的正式契约。短信发送、密码哈希、Cookie 签发与令牌撤销必须由后端负责。
