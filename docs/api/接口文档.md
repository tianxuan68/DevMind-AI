# DevMind AI 工作台 API 文档

服务入口：`http://localhost:8003`。启动命令：`uvicorn app.main:app --reload --port 8003`。

当前实现位于 `backend/app/api/workspace.py`，为前端联调提供内存数据实现；进程重启后会清空会话、消息、收藏和偏好数据。

## 已实现接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/knowledge-bases` | 知识库列表 |
| GET | `/api/v1/documents?knowledge_base_id=` | 文档列表与筛选 |
| POST | `/api/v1/sessions` | 创建会话 |
| GET | `/api/v1/sessions` | 历史会话列表 |
| GET | `/api/v1/sessions/{session_id}` | 会话及消息详情 |
| POST | `/api/v1/messages` | 创建用户消息与待生成 AI 消息 |
| GET | `/api/v1/messages/{message_id}` | 断线恢复时查询消息 |
| WS | `/api/v1/chat/stream?message_id=` | RAG 状态、token、引用与完成事件 |
| GET | `/api/v1/messages/{message_id}/citations` | 回答引用列表与可信度 |
| GET | `/api/v1/citations/{citation_id}` | 引用原文详情 |
| PUT/DELETE | `/api/v1/favorites/messages/{message_id}` | 收藏或取消收藏 |
| GET | `/api/v1/favorites` | 收藏回答列表 |
| GET | `/api/v1/me` | 当前用户 Mock 信息 |
| GET/PATCH | `/api/v1/me/preferences` | 读取和保存工作台偏好 |
| POST | `/api/v1/retrieval/test` | 检索测试，不生成 AI 回答 |

所有 HTTP 成功响应统一为：

```json
{ "request_id": "req_xxx", "data": {}, "error": null }
```

完整的请求字段、流式事件协议、页面映射与后续接口规划见：[工作台前后端接口契约.md](工作台前后端接口契约.md)。登录、注册、短信验证码与退出登录的约定见：[登录页接口契约.md](登录页接口契约.md)。
